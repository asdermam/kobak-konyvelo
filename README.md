# Kobak Könyvelőiroda – weboldal

Reszponzív, egyoldalas bemutatkozó weboldal a bonyhádi Kobak Könyvelő és Adótanácsadó Iroda Bt. számára.

**Élő oldal:** https://asdermam.github.io/kobak-konyvelo/

## Megnyitás

Az `index.html` közvetlenül megnyitható böngészőben, vagy a mappában futtatható egy egyszerű statikus webszerver:

```powershell
python -m http.server 4173
```

Ezután: `http://localhost:4173`

## Publikálás előtt
